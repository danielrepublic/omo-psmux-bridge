# Triage Labels

Skills 以五個正規 triage 角色說話。本檔案將這些角色對應到本 repo issue tracker 實際使用的標籤字串。

| Label in mattpocock/skills | Label in our tracker | 意思                            |
| -------------------------- | -------------------- | ------------------------------- |
| `needs-triage`             | `needs-triage`       | 維護者需要評估此議題            |
| `needs-info`               | `needs-info`         | 等待回報者補充更多資訊          |
| `ready-for-agent`          | `ready-for-agent`    | 已完整描述，可交由 AFK 代理執行 |
| `ready-for-human`          | `ready-for-human`    | 需要人工實作                    |
| `wontfix`                  | `wontfix`            | 不會處理                        |

當 skill 提到某個角色（例如「套用 AFK-ready triage 標籤」），使用本表對應的標籤字串。

右欄可自行編輯，以符合實際使用的標籤慣例。
