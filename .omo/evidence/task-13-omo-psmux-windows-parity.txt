== OPERATIONAL CONSTRAINT, NOT A PRODUCT BUG ==
The launcher must be invoked as `cmd /d /c <path>\psmux.cmd <args>` with the program
path UNQUOTED. Wrapping the line a second time ("/c ""path" args"") makes cmd
report "'\"path\"' 不是內部或外部命令". This host's install path contains no spaces,
so the unquoted form works; a path with a space would need the other form. A user
typing `psmux` in a shell never hits this, because the shell resolves the command
itself. It is a constraint on scripted invocation only, and it is why the harness
drives psmux.exe directly.
