Anything the user must know
----------------------------
- After this upgrade the doctor's STALE-SERVER gate is heuristic: the
  new shim mtime moved forward while older servers still run, so a
  long-lived psmux server can read as stale (false-positive path
  documented in the doctor output). If the doctor ever reports
  STALE FAIL on a server started before the upgrade, restart that
  server from a fresh shell — same guidance as any bridge upgrade.
- The installer's `Unblock-File -Recurse` error on PS 5.1 is cosmetic
  (install still RESULT=OK); suggested follow-up issue for repo-ops.
